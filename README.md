# Zotero Duplicate Cleaner 0.10.0

工具 → 文献资源整理，在 Zotero 主窗口内打开带图标的管理面板。

**名称搜索**：扫描后在搜索框输入资源名称，忽略大小写实时筛选，也可匹配所属父条目名称及资源键。清空搜索恢复全部结果。全选、取消选择与“处理选中”仅作用于当前搜索结果；被筛掉的资源会自动取消勾选。计数栏显示可见数、总数和已选数。Escape 在有搜索词时先清空搜索。

结果采用资源卡片：角色标签、资源名称、所属文献库、父条目、当前分类和处理去向分行显示；每条完整分类路径独立呈现，合并后的保留位置使用独立区域。判定依据、扫描规则、跳过原因默认折叠。

父子资源使用折叠层级：父条目显示为可展开标题，真正属于它的附件和笔记集中在其下。独立孤儿 PDF 保持独立来源卡片，不放入重复条目的父级折叠区；独立笔记和无效条目也保持独立卡片。

每个候选组显示所有涉及资源的来源：文献库、完整分类层级、多分类归属，以及附件／笔记所属父条目。未归类资源明确标为“未分类”。同时预览保留目标、分类合并后的预计位置和回收站去向；这些是 Zotero 分类归属，不表示移动磁盘文件。工具菜单入口也显示插件图标。

- **扫描重复**：普通条目候选、内容完全相同的 PDF、内容完全相同的笔记。PDF 与笔记仅在相同父条目下或独立资源之间归组；独立 PDF 与条目内 PDF 的对照规则继续保留。笔记按完整 HTML 比较，不凭标题、摘要或相似文本删除。含图片、关联资源或独有批注的资源保守跳过。
- **扫描无效项**：列出没有附件的条目、所有本地附件都已缺失的条目，以及可安全清理的缺失附件记录。远程 URL、等待下载或状态不明的附件不判为缺失。带笔记、批注或关联记录的候选受到保护。
- 每次扫描均默认不勾选。核对原因和保留对象后，全选或部分选择，再点 **处理选中** 确认。删除采用移入 Zotero 回收站，不自动清空回收站或直接删除真实文件。无附件文献仍可能有价值，不等于重复项。

扫描当前选中的整个文献库（不是仅当前分类），核对候选组后全选或逐组勾选，点击“合并选中”并确认。分组依据为相同条目类型与 DOI；没有 DOI 时使用完整标题。标题相同不保证内容相同，请核对日期和作者。

新增“内容相同的独立 PDF”分组：扫描包括子附件的整个文献库，按实际文件 SHA-256 比较独立 PDF 和普通条目自带 PDF。保留元信息评分最高的父条目及其附件；多父条目时不会因此删除其他父条目。把重复独立 PDF 移入回收站，分类转移到父条目，标签转移到保留附件。带批注、笔记或关系的独立 PDF、文件缺失或无法读取的附件均跳过。扫描、勾选和关闭不会修改文献。

普通条目重复组先保留有可用本地 PDF 的记录，再按字段和作者信息丰富度选择。合并前用其他记录补齐保留记录的空白字段和作者；已有非空字段不覆盖。确认合并后的主条目有可用 PDF，才将该重复组中的失效 PDF 附件记录移入回收站。带笔记、批注或关联记录的失效附件受到保护。没有替代项的唯一条目不会仅因附件缺失被清除。文件内容或父子关系在扫描后变化时会拒绝处理，需重新扫描。条目与自己的子附件不会被判定为一组重复。

## 构建

运行 `./build.ps1`，生成工作区中的 `zotero-dedup-plugin-0.7.0.xpi` 和同内容的 `zotero-dedup-plugin.xpi`。打包时将 resource-locations.js、resource-cleanup.js 与 bootstrap.js 合为单一入口，并包含 manifest.json 和 icons/icon.svg，不依赖旧 chrome 页面。
